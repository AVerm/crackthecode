# Crack the Code!

A solitaire deduction game for phones: find a three-digit code (each digit 1–5) by testing it against predicates that answer ⊤ or ⊥.

The whole game is one self-contained file, `index.html`, with no build step and no network requests. Open it in a browser or serve it with GitHub Pages (Settings → Pages → Deploy from a branch → `master`, `/ (root)`). The empty `.nojekyll` file tells Pages to serve the file as is.

Saved games and settings live in each player's browser, per site address.
